En desarrollo

Blog con investigación automatizada

Publicar con regularidad sin sacrificar la veracidad. En mis pruebas, un modelo de IA con búsqueda web inventó 4 de 8 enlaces supuestamente oficiales de WordPress.

Qué hice

  • Búsqueda con un SearXNG propio, limitada a documentación oficial.
  • Redacción con un modelo de lenguaje local, en mi propia GPU, a partir de las fuentes descargadas.
  • Un validador que aplica la guía editorial y exige que cada enlace sea una fuente real.
  • El borrador llega como pull request: lo reviso yo, GitHub Actions genera el HTML y se publica al aprobarlo.

Resultado

  • El validador ya frena enlaces inventados: en pruebas, un modelo se inventó el dominio blog.davidhuangxie.com y el borrador no pasó.
